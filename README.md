# homebrew-acctswap

Homebrew tap for [acctswap](https://github.com/000Janela000/acctswap): switch the account every Claude Code session on a machine uses.

```
brew install 000Janela000/acctswap/acctswap
```

The formula is written by `scripts/update-tap.sh` in the acctswap repo after each release; edits here are overwritten.
